StackLife's BackupTables.export/read and BackupRecord catalog adapt per-record JSON export and establishing identities before dependent records. Local differences: bounded category-specific JSONL, validated stable IDs (including occurrence original dates), independent category *replacement*, a single caller-owned Room transaction, and target-keystore activation. No Tasks.org SQL schema, preference-map restore, synchronization, analytics or legacy migration code is included.
